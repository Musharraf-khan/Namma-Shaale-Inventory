# 📚 Namma-Shaale Inventory

A smart Android-based school asset management system designed to help educational institutions digitally track, monitor, and maintain school resources such as lab equipment, sports kits, tablets, and classroom infrastructure.

Built as part of the **MindMatrix VTU Internship Program**.

---

## 🚀 Project Overview

Namma-Shaale Inventory acts as a **Digital Asset Auditor** that allows teachers and administrators to:

- Register school assets
- Perform monthly condition checks
- Log issues and damages
- Request repairs for damaged items
- Generate summary reports

---

## ✨ Features

### 📦 Asset Registration
- Add assets with:
  - Asset Name
  - Serial Number
  - Category
  - Description
  - Asset Photo

### 🩺 Condition Monitoring
- Track asset health:
  - Working
  - Needs Repair
  - Broken

### 📝 Issue Logging
- Record damages or missing items
- Add reason and date

### 🛠 Repair Request Management
- Track repair status
- Maintain repair history

### 📊 Dashboard & Analytics
- Total assets
- Damaged assets
- Pending repairs

### 📸 Camera Integration
- Capture asset images using CameraX
